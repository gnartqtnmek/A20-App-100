# DANH SÁCH ĐẦY ĐỦ CHỨC NĂNG HỆ THỐNG LMS ĐẠI HỌC

Tài liệu này tổng hợp đầy đủ các chức năng của hệ thống LMS dành cho môi trường đại học theo 5 đối tượng sử dụng chính:

1. Sinh viên
2. Giảng viên
3. Quản trị viên hệ thống — Admin
4. Khoa / Bộ môn / Phòng đào tạo
5. Cố vấn học tập
